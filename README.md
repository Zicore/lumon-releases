# Lumon – releases

Downloads for **Lumon**, a system monitor in Rust that explains why the computer hangs or the fans spin up, instead of only listing what is running right now.

This repository only holds the release builds. The source code is not public yet.

## Download

Get the latest build from [Releases](https://github.com/Zicore/lumon-releases/releases).

- **Windows (x86-64):** portable ZIP. Unpack anywhere and start `lumon.exe`; no installation or administrator rights needed. See `README.txt` in the archive.
- **Linux:** Lumon runs on Linux too, but there is no ready-made package yet.

These are pre-releases. The builds are not code-signed yet, so Windows SmartScreen may warn on first start ("More info" → "Run anyway").
